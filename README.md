### 📝 Abstract
A Java-based desktop application designed to track student grades and monitor attendance statistics. It allows for inputting academic performance metrics, calculating averages, and logging weekly attendance records to verify minimum university criteria are met.

---

### ⚙️ Setup and Execution Instructions
1. Clone the repository.
2. Open the project folder in VS Code.
3. Compile and run `Main.java` located inside the `/src` folder.
